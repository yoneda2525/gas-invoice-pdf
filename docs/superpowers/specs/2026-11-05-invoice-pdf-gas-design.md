# 見本1：請求書PDF自動作成（GAS） — 設計書

> 日付：2026-11-05
> 目的：ココナラ・クラウドワークスで見せる見本。動く・きれい・インボイス対応。

## 1. シート構成

### 「設定」シート（A列＝項目名、B列＝値）
| 項目 | 例 |
|---|---|
| 自社名 | サンプル商事 |
| 住所 | 東京都〇〇区… |
| 振込先 | 〇〇銀行 〇〇支店 普通 1234567 |
| インボイス登録番号 | T1234567890123 |
| 保存フォルダ名 | 請求書 |

### 「明細」シート（1行目＝見出し）
| 列 | 内容 | 必須 |
|---|---|---|
| 請求番号 | INV-0001 | ○ |
| 請求日 | 2026/11/05 | ○ |
| 客名 | 株式会社サンプル | ○ |
| 品目 | Webサイト保守 | ○ |
| 数量 | 1 | ○ |
| 単価 | 30000 | ○ |
| 税率 | 10% または 8% | ○ |
| 状態 | 未作成 / 作成済み / エラー：… | ― |
| PDFリンク | （自動で入る） | ― |

同じ請求番号の行＝1枚の請求書の明細。

### 「ひな形」シート
請求書の見た目。決まったセルに値を流し込む。明細は最大15行。

## 2. 動き

1. メニュー「請求書 → PDF作成」。
2. 状態が「未作成」の行を集め、請求番号ごとにまとめる。
3. 各請求について：
   1. 入力チェック。
   2. 金額計算（下記）。
   3. ひな形をコピーして値を埋める。
   4. PDF化し、Driveの保存フォルダへ（無ければ作る）。ファイル名：`請求番号_客名.pdf`
   5. 該当行の状態を「作成済み」、PDFリンクを記入。
   6. コピーしたシートを消す。
4. 最後に「作成 N件、エラー M件」を表示。

### 金額計算（インボイス方式）
- 税率ごとに税抜小計を出す。
- 税額＝税率ごとの小計 × 税率。端数は**1税率につき1回だけ**切り捨て。
- 合計＝税抜小計の合計＋税額の合計。

## 3. エラー処理

- 必須欄が空、数量・単価が数でない、税率が10%/8%以外、明細が15行超 → その請求の全行を「エラー：〇〇」にして飛ばす。
- 1件こけても他の請求は続ける。
- 予期しない例外も、その請求だけエラーにして続ける。

## 4. コード構成

| ファイル | 役割 | 依存 |
|---|---|---|
| `src/calc.js` | 金額計算・入力チェック・グループ化。純粋関数のみ | なし |
| `src/sheet.js` | シートの読み書き | SpreadsheetApp |
| `src/pdf.js` | ひな形埋め・PDF化・保存 | SpreadsheetApp, DriveApp |
| `src/main.js` | メニュー登録・全体の流れ | 上の3つ |

`calc.js` はGASでもNode.jsでも動く形で書く。

## 5. テスト

- `calc.js` を Node.js 標準のテスト機能（`node:test`）でテスト（TDD）。追加インストール不要。
  - 10%のみ / 8%のみ / 混在
  - 端数切り捨てが税率ごとに1回か
  - 必須欄の空、型エラー、税率エラー、16行
  - 請求番号ごとのグループ化
- PDF作成は、テスト用シートで手動確認（チェックリストをREADMEに書く）。
